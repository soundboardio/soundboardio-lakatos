# Miluju svoji práci

> Plugin for [SoundBoardio.com](https://soundboardio.com), a free GitHub-powered soundboard app.

31 Czech sound quotes, playable in the browser and installable on your phone as an app.

**▶ [Open the soundboard](https://soundboardio.com/app/lakatos/?utm_source=github&utm_medium=readme&utm_campaign=lakatos)**

> Video z roku 2010 zachycuje strasti při opravě traktoru LKT (Lesní Kolový Traktor, známý také pod lidovým názvem "Lakatoš").

Board by [Sám Život](https://aquasoup.com).

## Missing a quote?

- [Suggest it](https://github.com/soundboardio/soundboardio-lakatos/issues/new?title=Quote%20suggestion&body=Quote%3A%0AWhere%20it%E2%80%99s%20from%20%28link%2C%20time%29%3A%0A) and say what it is and where it comes from (link, time).
- Or send a pull request: drop the mp3 into `sounds/` and add a tile to [`soundboardio.json`](soundboardio.json). A transcript in `lyrics` follows [this format](https://github.com/soundboardio/soundboardio-developers#lyrics-transcript).

## Want your own soundboard?

All it takes is a public GitHub repository and one `soundboardio.json` file. No build, no deploy, free.

Guide, generator and validator: **[soundboardio.com/create](https://soundboardio.com/create/?utm_source=github&utm_medium=readme&utm_campaign=lakatos)** (in Czech: [soundboardio.com/cs/create](https://soundboardio.com/cs/create/?utm_source=github&utm_medium=readme&utm_campaign=lakatos)).
